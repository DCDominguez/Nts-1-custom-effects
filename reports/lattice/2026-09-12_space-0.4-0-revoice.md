## Why

The exact A-class release-candidate physical test found that SPACE 0.3-0:

- loaded and produced its intended echo/spatial behavior;
- was still very subtle even at full MIX;
- distorted when run with modulation;
- retained the echo effect underneath the distorted quality.

The user classified SPACE as the main LATTICE unit needing a rework rather than a simple level increase.

CORE 0.3-1 has now passed its focused standalone upper/max-TIME test and its CORE + FIELD 0.1-2 combination test, so project priority moves to SPACE.

- the original NTS-1 Owner's Manual still documents REVERB selection and user effects;
- the current Korg support page still lists the original NTS-1 Owner's Manual and System Updater 1.20.

## Diagnosis from the 0.3 source

SPACE 0.3 used:

- stereo predelay;
- four early-reflection reads per channel;
- two stereo all-pass diffusion stages;
- four continuously interpolated/modulated FDN read heads;
- four low-pass feedback states;
- per-line feedback soft limiting plus final output limiting;
- an output guard that only recovered when the raw peak fell below its ceiling.

Two concrete engineering concerns were identified without claiming measured MkI CPU telemetry:

1. **runtime complexity:** the architecture performed many interpolated reads and nonlinear feedback operations every sample;
2. **stale guard attenuation:** after a large peak, the 0.3 guard could stay at an unnecessarily low gain while raw room peaks remained above the guard ceiling, contributing to a room that could feel persistently suppressed.

The combination distortion may involve runtime, gain interaction, or both. No exact CPU percentage exists, so 0.4 is designed to reduce both risks without claiming either was the sole cause.

## What changed

### 1. Memory/runtime simplification

0.4 keeps one stereo predelay and a four-line FDN, but removes one entire stereo diffusion bank and halves each FDN backing buffer from 8192 to 4096 floats.

Approximate external float history changes from:

- 0.3: 46,?00 floats across predelay/diffusion/FDN banks (about 184 KiB of float storage);
- 0.4: 28,672 floats (about 112 KiB of float storage).

The exact linker/build result remains authoritative; this estimate describes source arrays only.

### 2. Fixed FDN read heads

The four FDN delay lines now use fixed integer reads:

- 1423 samples
- 1987 samples
- 2671 samples
- 3433 samples

0.3's four continuously interpolated, modulation-shifted FDN reads are removed.

### 3. DRIFT moved out of delay-time interpolation

`DEPTH = DRIFT` still creates motion, but now controls:

- damping character;
- stereo output/cross geometry;
- side injection amount;
- a cheap triangle-LFO wander term.

This keeps movement while making the room less expensive and less prone to delay-read artifacts under load.

### 4. Stronger intentional early voice

The early echo/spatial identity is preserved with a fixed predelay and two early taps per channel. The early/tail balance changes with SPACE so small rooms speak more clearly while larger SPACE values hand more weight to the late field.

### 5. Feedback path made mostly linear

0.3 continuously soft-limited all four FDN writes. 0.4 uses stable feedback capped at approximately 0.76 and an emergency-only hard bound at ±0.985 inside the FDN state.

The intent is to avoid hearing feedback waveshaping as a constant part of the room when another ModFX raises crest factor or spectral density.

### 6. MIX revoiced for standalone use

0.3 retained 45% dry signal at full MIX. 0.4 changes the output law to:

- `dry_gain = 1 - 0.88 * MIX`
- `wet_gain = (0.78 + 0.30 * MIX) * MIX`

At full MIX the path is therefore intentionally wet-dominant rather than dry-dominant.

This is not a blind global gain boost: early/tail structure, runtime cost, feedback behavior and guard behavior were changed together.

### 7. Guard recovery corrected

The output guard still catches overload immediately, but its gain now recovers toward the **currently safe target gain** even while the raw room remains above the ceiling. It no longer waits for raw peak to drop entirely below the ceiling before recovery can begin.

Guard ceiling is now 0.90.

## Controls

NTS-1 nomenclature remains unchanged:

- `TIME` → SPACE
- `DEPTH` → DRIFT
- `SHIFT+DEPTH` / `k_user_revfx_param_shift_depth` → MIX

No user-facing control remap is introduced.

## Sound-quality intent

SPACE 0.4 should:

- be clearly audible and useful around middle MIX;
- become strongly wet/spatial at full MIX;
- retain a recognizable early echo statement before the diffuse tail;
- feel dark, wide and alive without relying on hot nonlinear feedback;
- recover level naturally after peaks;
- remain suitable as a standalone reverb, not merely as a LATTICE system helper.

## Runtime/headroom intent

The redesign removes:

- one full stereo diffusion stage;
- fractional interpolation from the four FDN read heads;
- delay-time modulation on those FDN reads;
- continuous division-based soft limiting on all four feedback writes.

It also reduces FDN storage and fixes stale guard attenuation.

This is expected to provide more MkI runtime margin and cleaner combination behavior, but only physical testing can establish the actual device result.

## A-class test changes

The dedicated SPACE harness now additionally requires:

- useful middle-MIX output level;
- materially wet full-MIX identity;
- explicit early echo/spatial delivery;
- no persistent post-overload guard collapse;
- actual production CORE 0.3-1 → SPACE chain stays finite, bounded and delivers useful audio;
- existing SPACE persistence, DRIFT, stereo, rest, reset and long-wrap/soak contracts remain.

The chain test is a host-level signal/state check only; it does not claim ARM timing equivalence.

## Physical MkI gate

After host/A-class/ARM PASS, the exact 0.4-0 binary should be tested for:

1. load/select and basic audio;
2. standalone SPACE around middle MIX — effect should be clearly present;
3. standalone full MIX — room should be strong and enjoyable rather than faint;
4. TIME/SPACE sweep — early voice should hand naturally into a larger tail;
5. DEPTH/DRIFT sweep — motion should remain audible without rough modulation artifacts;
6. run after a ModFX and listen specifically for the previous distorted sound quality;
7. check that level does not collapse after a loud passage.

Do not infer support for simultaneous user DELAY + user REVERB on MkI; this rework is about SPACE as a standalone reverb and after a modulation effect.
