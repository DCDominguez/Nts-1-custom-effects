## Why 0.4-1 changes the guard before doing another topology rewrite

SPACE 0.4-0 still contains a sample-by-sample dynamic peak guard:

- if raw output exceeds the guard ceiling, gain is immediately changed to `ceiling / peak`;
- the gain is therefore audio-dependent on every sample while the guard is active;
- complex ModFX output can plausibly make that limiter/guard audible even when the final samples remain numerically bounded.

The A-class host test for 0.4-0 proved finite/bounded output and useful delivery, but it did **not** reject frequent internal FDN bounding or frequent output-guard action. A bounded waveform can still be audibly distorted.

Pure runtime overload also remains possible. However, other repository reverbs use substantial delay/read processing and the latest suite report did not identify the same universal ModFX + reverb failure outside SPACE. It is therefore useful to isolate SPACE's own nonlinear/headroom behavior before discarding its current room topology.

## What changed in 0.4-1

### 1. Dynamic output guard removed

The sample-by-sample gain guard is removed completely.

There is no longer a continuously changing gain multiplier after SPACE's wet/dry sum. Final output has only an emergency hard bound at ±0.995.

This is deliberately a one-variable diagnostic at the output stage: if the previous guard was creating audible distortion on ModFX-fed material, 0.4-1 should remove that mechanism.

### 2. More internal FDN headroom

To make removal of the dynamic guard safe, 0.4-1 reduces energy **inside** the regenerative network:

- diffusion feed reduced from `0.68 / 0.52` to `0.56 / 0.40` for predelay/early components;
- FDN direct-mid injection reduced from `0.10` to `0.055`;
- FDN diffuse-mid injection reduced from roughly `0.30–0.38` to `0.20–0.25`;
- side injection reduced similarly;
- maximum feedback reduced from approximately `0.92` to approximately `0.89`.

The goal is to prevent the FDN safety bound from becoming part of the audible sound when driven by ModFX.

### 3. Presence moved to readout rather than loop drive

SPACE should not become faint again simply because loop injection is safer.

0.4-1 therefore keeps output presence by weighting the already-generated room more strongly at readout:

- early voice remains strong;
- tail voice is increased relative to the safer internal injection;
- full MIX remains wet-dominant;
- no global blanket attenuation is added.

The design principle is: **quiet/safe regenerative state, strong audible readout**.

### 4. Hidden clipping is now measurable

Two diagnostic counters were added to the actual production DSP:

- `s_feedback_clamps`: counts FDN state-bound hits;
- `s_output_clamps`: counts emergency final-output-bound hits.

They are reset with normal effect state and are exercised by the A-class host harness. This closes a gap in the 0.4-0 test, which could accept audio that was finite and bounded while still repeatedly touching nonlinear safety limits.

## A-class harness changes

The SPACE project-specific test now requires:

- mid MIX remains clearly audible;
- full MIX remains clearly wet;
- normal mid/full-MIX sustained sources produce **zero** hidden FDN clamps and **zero** output clamps;
- large SPACE still has materially longer persistence than small SPACE;
- DRIFT still reaches output and creates stereo motion;
- maximum SPACE still decays toward rest;
- production CORE 0.3-1 → SPACE chain remains finite/bounded/useful **and** produces zero FDN/output clamp hits;
- production IRONROT → SPACE is added as a second real ModFX stress path and must also produce zero FDN/output clamp hits;
- suspend/resume clears all room state and diagnostic counters;
- long wrap/control soak remains finite and bounded.

The host chains still do **not** measure MkI cycle/deadline margin.

## Sound intent

Preserve the 0.4 goals:

- clearly audible around middle MIX;
- strong wet spatial ownership at full MIX;
- obvious early echo/spatial statement;
- dark moving stereo field;
- larger TIME/SPACE values create a meaningfully longer room.

The only sonic compromise deliberately accepted is slightly less regenerative drive inside the FDN in exchange for cleaner combination behavior.

## Runtime/headroom intent

0.4-1 is primarily a nonlinear/headroom diagnostic, not yet the proposed minimum-runtime rewrite.

It does remove the guard's conditional floating-point division from the output path whenever peaks exceed the old ceiling, but the four-line FDN and one diffusion stage remain.

If 0.4-1 still distorts after ModFX on the physical MkI despite zero host clamp evidence, the next diagnostic should be architectural: reduce SPACE to a substantially cheaper two-line/cross-coupled room and cut external-memory reads/writes rather than continuing to tune gain.
