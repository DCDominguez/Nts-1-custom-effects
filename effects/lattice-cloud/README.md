# LATTICE CLOUD

LATTICE CLOUD is the `revfx` companion to LATTICE CORE.

Its job is not to add a generic room around the generated phrase. It progressively removes the boundaries between LATTICE microloops until their intervals read as one ambient harmonic object.

## Controls

| NTS-1 | Role |
|---|---|
| TIME | **SPACE** — scales the sparse reflection and FDN dimensions / tail |
| DEPTH | **COALESCE** — sparse distinguishable fragments at low values → dense diffused cloud at high values |
| SHIFT+DEPTH | **MIX** — dry/wet balance |

M1 uses irregular early reflections feeding a modulated four-line FDN. COALESCE crossfades from the sparse reflection field toward the dense network while also changing diffusion/injection/damping. Explicit wet-path headroom and soft bounded feedback are used to avoid the clipping behavior previously observed in NEBULA.
