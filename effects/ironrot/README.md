# IRONROT

IRONROT is a clean-room Human Soon distortion-family `modfx` for the original Korg Nu:Tekt NTS-1 digital kit MkI.

| NTS-1 modulation control | IRONROT function |
|---|---|
| TIME | **CHARACTER** — dark compression → bright corroded edge |
| DEPTH | **CORROSION** — drive and wet intensity |

The design combines a bounded rational saturator with tone-dependent pre-emphasis and a controlled cubic erosion term. It is intentionally not a recreation of any commercial algorithm.

Status: M1 source ready for CI. Hardware validation required before additional modes.
