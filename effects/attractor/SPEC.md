# ATTRACTOR Specification

Target: NTS-1 MkI `modfx`, API `1.1-0`.

## M1
- Coupled bounded chaotic maps.
- TIME = RATE.
- DEPTH = ORBIT.
- Smoothed pan target.
- Stereo input retained through a mid/side-aware motion stage.
- DEPTH=0 returns the original stereo signal.

## Deferred
Alternate attractors, tempo lock, orbit presets and external sync wait for hardware QA.
